# Location-Based WebAR Navigator

یک مسیریاب واقعیت افزوده مکان‌محور که مقصد را از روی نقشه دریافت کرده و نشانگر آن را در مختصات واقعی GPS نمایش می‌دهد.

## Features
- Destination selection on a Leaflet map
- GPS-anchored AR marker
- Live distance and compass guidance
- Configurable arrival radius
- Persian labels rendered as canvas textures
- Shareable destination URLs
- Mobile-first RTL interface

## Stack
HTML, CSS, JavaScript, Leaflet, OpenStreetMap, A-Frame, AR.js, Geolocation API, Device Orientation API

## Run
Serve the repository over HTTPS or localhost and open `/04-location-based-webar/` on a supported mobile browser. Allow camera, location, and orientation permissions.
